This is a digital garden: a growing collection of notes that are connected by ideas, not just sorted by date.

Start with systems thinking for a framework, or visit knowledge architecture for the structure behind the garden.

How to add a page
  1. Create an HTML fragment in digital-garden/pages/.
  2. Add its id, parentId, title, and file path to garden.json.
  3. Put matching data-garden-id and data-parent-id attributes on the fragment's article.
